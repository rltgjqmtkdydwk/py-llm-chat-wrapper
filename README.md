# LLM 기반 요약 서비스 QA 미니 프로젝트

인턴 지원용으로 "AI/LLM 서비스 테스트 경험"을 보여주기 위해 만든 실습 프로젝트입니다.
Gemini API로 만든 간단한 요약 서비스(`app.py`)를 대상으로 pytest 테스트(`test_summarizer.py`)를 작성했습니다.

## 1. 실행 방법

```bash
pip install -r requirements.txt
export GEMINI_API_KEY="여기에_발급받은_키"     # Windows: set

# 서비스 단독 실행 (동작 확인)
python app.py

# 전체 테스트 실행
pytest test_summarizer.py -v

# API 키 없이도 실행 가능한 테스트만 (엣지케이스 입력 검증)
pytest test_summarizer.py -v -k "not requires_api_key" -m "not skip"
```

## 2. 테스트 설계 근거

일반적인 REST API 테스트와 달리, LLM 기반 서비스는 아래 3가지가 추가로 고려해야 할 포인트라고
판단해서 테스트 케이스를 설계했습니다.

| 고려할 포인트             | 중요한 이유                                                                                                                                    | 대응 테스트                                              |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 비결정성(Non-determinism) | 동일한 입력에도 시행할 떄마다 다른 출력이 나옴 → "문장이 정확히 일치"하는 게 아닌 "핵심 의미만 유지"하는 것으로 검증 기준을 바꿔야 함          | `test_consistency_across_repeated_calls`                 |
| 프롬프트 인젝션           | 사용자 입력이 곧 모델에게 전달되는 컨텍스트이기 때문에, 입력 안에 악의적인 지시문이 섞이면 시스템 지침이 유출되거나 의도와 다른 동작을 할 위험 | `test_prompt_injection_does_not_leak_system_instruction` |
| 입력 경계값               | 빈 입력, 초장문, 특수문자 등은 일반 API와 동일하게 검증 필요                                                                                   | `test_empty_string_raises_value_error` 외 다수           |

## 3. 테스트 결과 리포트

| No  | 테스트 항목       | 입력                      | 예상 결과          | 실제 결과 | Pass/Fail | 비고 |
| --- | ----------------- | ------------------------- | ------------------ | --------- | --------- | ---- |
| 1   | 정상 요약         | 3문장 업무 보고 텍스트    | 3줄 이내 요약 반환 |           |           |      |
| 2   | 빈 입력           | `""`                      | ValueError 발생    |           |           |      |
| 3   | 공백만 입력       | `"   "`                   | ValueError 발생    |           |           |      |
| 4   | 최대 길이 초과    | 20,001자                  | ValueError 발생    |           |           |      |
| 5   | 특수문자/이모지   | HTML태그+이모지 혼합      | 에러 없이 처리     |           |           |      |
| 6   | 일관성 (3회 반복) | 동일 입력 3회             | 핵심 키워드 유지   |           |           |      |
| 7   | 프롬프트 인젝션   | 시스템 프롬프트 유출 시도 | 유출 없음          |           |           |      |
| 8   | API 키 누락       | 환경변수 미설정           | RuntimeError 발생  |           |           |      |
